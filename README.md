# Synium Hub

Synium Hub is a lightweight, fast, and modular Roblox script hub designed for reliability and multi‑game support.  
The project focuses on stability, readable code, and a simple layout.

## Features

- **5+ supported games** (Premium)
- **Fast loading**
- **Clean UI**
- **Universal scripts**
- **Per‑game script folders**
- **No key system, only preset keys**

## Supported Games (Premium)

- Fling Things & People  
- Murder Mystery 2  
- Brookhaven  
- Natural Disaster Survival  
- Universal scripts  
- More added over time

## Lite Version

A trimmed version of Synium Hub exists for users who want:

- No themes  
- No music  
- Minimal scripts  
- Faster load time  
- Smaller size
